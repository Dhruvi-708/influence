# INFLUENCE

**Control the story. Change the world.**

INFLUENCE is a single-player browser game about media framing, public reaction and conflict escalation.

You do not control armies. You control a media organization.

Each turn, a new event arrives with confirmed facts, unknowns and risks. You decide what the public sees. NPC factions react to the information environment through simple rule-based changes in tension, anger, trust and influence.

## Prototype scope

- Single player
- 3 NPC factions
- 4 news events
- 4 reporting choices per event
- 3 possible outcomes:
  - De-escalation
  - Escalation
  - Information Chaos
- No backend
- No accounts
- No external libraries

## Run locally

Open `index.html` in a browser, or serve the folder with any simple local web server.

## MIL connection

The prototype is designed to make media and information literacy experiential rather than lecture-based. Players see how framing, uncertainty, selective emphasis and sensationalism can change public reaction and therefore alter the simulated world.

## Files

- `index.html` — page shell
- `style.css` — minimal visual design
- `game.js` — game state, events, NPC rules and outcomes

## Future direction

A full version could add multiple scenarios, richer NPC behavior, sourced media items, AI-generated content verification rounds, replay statistics and multiplayer competition.


### Prototype duration
The current prototype is designed as an approximately 5-minute single-player experience with eight escalating news events and three possible story outcomes.
